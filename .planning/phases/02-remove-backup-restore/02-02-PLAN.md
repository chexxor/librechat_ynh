  <files>scripts/backup</files>
  <action>
Replace the stub in `scripts/backup` following 02-RESEARCH.md Pattern 2 (with the recommended variant b — explicit stop + restart):

1. **IMPORTANT cwd context:** this script runs with cwd = archive staging dir, and `_common.sh` lives at a different relative path than in install. Start with:
   `source ../settings/scripts/_common.sh` then `source /usr/share/yunohost/helpers`, then `ynh_abort_if_errors`.
2. Read settings: `db_name=$(ynh_app_setting_get --key=db_name)` with non-empty sanity check (`ynh_die` if empty).
3. **Declare files to backup FIRST** (ynh_backup declares, YNH core copies later — keep Wekan's declaration-then-dump order so declarations register before any stops):
   - `ynh_backup "$install_dir"` — build artifacts + librechat.env/yaml (env is chmod 600; core handles it)
   - `ynh_backup "$data_dir"` — meilisearch index dir
   - `ynh_backup "/etc/nginx/conf.d/$domain.d/$app.conf"` — nginx config
   - Do NOT back up systemd units — restore regenerates from conf/ templates (single source of truth, fresh secret injection).
   - Do NOT back up /usr/bin/meilisearch — restore re-downloads via ynh_setup_source.
4. **Stop services for coherence** (meili LMDB copied mid-write can corrupt; mongo writes quiesced):
   `ynh_systemctl --service=$app --action=stop` then `ynh_systemctl --service=meilisearch --action=stop`.
5. **Mongo dump** — keep the exact Wekan form with NO absolute path (Pitfall 2: YNH core sets cwd to the staging dir and sweeps ./dump.bson into the archive):
   `ynh_mongo_dump_db --database=$db_name > ./dump.bson`
   Do not "fix" this to a fixed path.
6. **Explicitly restart both services at the end** (Pitfall 3: YNH core may not restart them; app must stay up after backup, serving phase success criterion "non-destructive backup"):
   `ynh_systemctl --service=meilisearch --action=start --wait_until_running --timeout=300` then `ynh_systemctl --service=$app --action=start` (meili first, mirrors install start order), then final `ynh_script_progression`.

<task type="auto">
  <name>task 2: Implement scripts/restore (full recovery with dependency re-provisioning)</name>
  <files>scripts/restore</files>
  <action>
Replace the stub in `scripts/restore` following 02-RESEARCH.md Pattern 3. Critical invariants: (a) services start LAST (Pitfall 7 — LibreChat starting before mongorestore could create conflicting documents), (b) all dependency re-provisioning helpers are idempotent and called unconditionally, (c) `../settings/scripts/_common.sh` sourcing (same special path as backup).

Order:
1. `source ../settings/scripts/_common.sh`, `source /usr/share/yunohost/helpers`, `ynh_abort_if_errors`.
2. Read persisted settings (YNH core restores settings.json automatically):
   `db_name=$(ynh_app_setting_get --key=db_name)` with sanity check + die; `db_user=$db_name`.
3. Re-provision MongoDB server if absent (idempotent): `ynh_install_mongo` — no args, uses `$mongo_version="7.0"` global from _common.sh. Do NOT use the legacy `--mongo_version=` flag form (Wekan shows it, but v2.1 docs deprecate it).
4. Restore all declared paths from archive: `ynh_restore_everything` (install_dir, data_dir, nginx conf).
5. Restore Mongo data: `ynh_mongo_database_exists --database=$db_name` is not needed as a branch — run `ynh_mongo_restore_db --database=$db_name < ./dump.bson` unconditionally (fresh machine → DB may or may not exist; mongorestore handles both).
6. Re-provision Node with scripted fallback (research Open Question 3 — LOW confidence on whether v2 core re-injects, so guard): `nodejs_version="${nodejs_version:-24}"` before `ynh_nodejs_install`. Write the literal fallback `24` matching manifest `[resources.nodejs]` version and the STATE.md locked decision.
7. Re-download meilisearch binary (not in archive): `ynh_setup_source --dest_dir=/usr/bin --source_id=meilisearch` then `chmod +x /usr/bin/meilisearch`. Uses manifest per-arch URL + sha256 — zero duplication with install.
8. Regenerate BOTH systemd units from templates (do NOT restore unit files from archive):
   `ynh_config_add_systemd --template=librechat.service` and `ynh_config_add_systemd --template=meilisearch.service --service=meilisearch` — fresh `__DATA_DIR__`/`__MEILI_MASTER_KEY__` injection from settings.
9. Register in YNH monitoring: `yunohost service add $app --description="LibreChat daemon" --log="/var/log/$app/$app.log"` and `yunohost service add meilisearch --description="Meilisearch search engine" --log="/var/log/meilisearch/meilisearch.log"` (match the descriptions/args used in scripts/install).
10. Start LAST, meili first (mirrors install Step 9):
    `ynh_systemctl --service=meilisearch --action=start --wait_until_running --timeout=300`, then `ynh_systemctl --service=$app --action=start`, then `ynh_systemctl --service=nginx --action=reload`.
11. Final `ynh_script_progression "Restoration of $app completed"`.
