  <name>task 1: Add the lint-only GitHub Actions workflow</name>
  <files>.github/workflows/lint.yml</files>
  <action>
    Create `.github/workflows/lint.yml` with:
    - Triggers: `push` (all branches) + `pull_request`; NO `pull_request_target`; top-level `permissions: contents: read`.
    - Three parallel jobs, each `runs-on: ubuntu-latest` with `timeout-minutes: 10`:
      1. `package-linter` — checkout; setup-python 3.12; `git clone --depth 1 .../package_linter /tmp/pl`; `pip install -r /tmp/pl/requirements.txt`; run `python package_linter.py "$GITHUB_WORKSPACE"` from `/tmp/pl` (assert text-mode exit code only).
      2. `shellcheck` — checkout; `sudo apt-get update && sudo apt-get install -y shellcheck`; `shellcheck scripts/_common.sh scripts/install scripts/remove scripts/upgrade scripts/backup scripts/restore scripts/run_lint.sh scripts/setup_pc_env.sh scripts/redact_pc_logs.sh`.
      3. `toml-schema` — checkout; setup-python 3.12; `pip install jsonschema`; `python scripts/lint_toml.py`.
    - No step anywhere attempts a container build or `package_check`.
  </action>
</task>
