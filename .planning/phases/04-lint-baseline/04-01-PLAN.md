  <name>task 2: Pin LF line endings via .gitattributes</name>
  <files>.gitattributes</files>
  <action>
Create `.gitattributes` at the repo root pinning LF for shell scripts and text files, and marking images binary. Content:

```
* text=auto eol=lf
*.sh text eol=lf
scripts/* text eol=lf
manifest.toml text eol=lf
*.png binary
*.jpg binary
*.jpeg binary
*.gif binary
*.webp binary
```

Rationale to encode as a short comment block: this repo has no `.gitattributes` and the dev box has `core.autocrlf=true`. A Windows checkout can convert `scripts/*` to CRLF, which breaks `#!/bin/bash` (`bad interpreter`), trips shellcheck SC1017, and can confuse the linter's parsing (Pitfall 4). Do NOT rely on `core.autocrlf` alone.

After writing, verify scripts are still LF (they already are — this file prevents future drift, it does not rewrite existing files):
- `git ls-files --eol scripts/` must show `i/lf w/lf` for all 6 script files (no `i/crlf`/`w/crlf`).

Do NOT run `git add --renormalize` (unnecessary — files are already LF; renormalizing risks touching working files).
