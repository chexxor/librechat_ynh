Edit `conf/nginx.conf` inside the `location __PATH__/ { ... }` block:

1. Delete the "Standard proxy headers" comment and the 4 plain header lines (current lines 24–28):
```

  proxy_set_header Host $host;
  proxy_set_header X-Real-IP $remote_addr;
  proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
  proxy_set_header X-Forwarded-Proto $scheme;
```
These are supplied by `include proxy_params_no_auth;` (line 30) — the linter flags them as redundant. Do NOT remove the `include proxy_params_no_auth;` line.

2. Strengthen the existing WebSocket comment (current lines 15–18) so it explicitly states retention is deliberate and linter-flagged-but-accepted. Replace the existing short comment with a multi-line comment that says (paraphrase but keep the substance):
```
  # WebSocket support — REQUIRED for LibreChat real-time features.
  # NOTE (linter): package_linter flags the 'Upgrade' header as a greylist
  # redundancy and the 'Connection' value as overriding the default. These are
  # DELIBERATELY RETAINED: LibreChat's WebSockets/SSE do not work without
  # proxy_http_version 1.1 + Upgrade + Connection. See 04-SCOPE-EXEMPTIONS.md.
```
Keep the three active lines that follow it untouched:
```
  proxy_http_version 1.1;
  proxy_set_header Upgrade $http_upgrade;
  proxy_set_header Connection "upgrade";
```

4. Do NOT attempt to also remove the `Upgrade`/`Connection` lines — locked decision 3 forbids trading a working feature for a warning.

Avoid: changing `"upgrade"` to `$connection_upgrade` (would change behavior), reordering directives, or touching indentation style elsewhere.
