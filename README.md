## Overview

LibreChat is a multi-provider LLM chat UI — bring your own API keys for OpenAI, Anthropic, Ollama, OpenRouter, and more, and chat with whichever model you prefer from a single interface.

This YunoHost package installs LibreChat natively with one command, including a working MongoDB database and Meilisearch search engine. HTTPS is provisioned automatically via YunoHost's Let's Encrypt integration.

**Shipped version:** 0.8.8-rc3~ynh2

## Disclaimers / important information

* No LLM provider is configured by default. You must edit `librechat.yaml` and add your own API keys before you can chat.
* Registrations are closed by default (`ALLOW_REGISTRATION=false`); users are created by the admin via the built-in admin panel.
* Meilisearch search is disabled by default (`SEARCH=false`); enable it in `librechat.env` and restart the service.
* This app is not yet part of YunoHost's application catalog. Catalog-dependent linter checks are documented as out-of-scope-by-design for this milestone.
* Single-instance only: the Meilisearch wiring (shared port 7700 / service name) currently prevents multi-instance installs.
